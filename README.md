# Awesome Space Career Resources [![Awesome](https://awesome.re/badge-flat.svg)](https://awesome.re)

Curated lists for breaking into the space industry: companies that hire, internships, U.S. military SkillBridge partners, conferences, media, books, and open-source tools you can practice with.

Built for security engineers, satellite/systems engineers, IT, and anyone else trying to find a real starting point — not another generic “space is hard” thread.

## How to use this repo

1. **Browse employers** in [Jobs](AwesomeSpaceJobs.md), then cross-check seasonal openings in [Internships](AwesomeSpaceInternships.md) or [SkillBridge](AwesomeSpaceSkillbridges.md) if those paths apply.
2. **Learn in public** with something from [Open Source](AwesomeSpaceOpenSource.md) — TLEs + Skyfield/Orekit, cFS/F´ on a sim, or a SPARTA / Hack-A-Sat writeup beats another vague resume bullet.
3. **Stay current** via [Media](AwesomeSpaceMedia.md) and [Books](AwesomeSpaceBooks.md); use [Conferences](AwesomeSpaceConferences.md) when you want face-time with operators and hiring managers.

Postings rotate constantly. Always confirm on the employer’s careers page before you apply.
